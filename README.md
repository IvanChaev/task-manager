# Task Manager 📋

Лёгкий, современный десктопный таск-менеджер с Kanban-доской, тегами, приоритетами, дедлайнами и удобным графическим интерфейсом. Написан на чистом Python с использованием `tkinter`.

---

## ✨ Основные возможности

- **Kanban-доска:** 3 колонки статусов (*«К выполнению»*, *«В процессе»*, *«Готово»*) с поддержкой карточек задач.
- **Приоритеты:** Разделение задач по приоритетам (*Высокий*, *Средний*, *Низкий*) с цветовой индикацией.
- **Система тегов:** Создание и назначение цветных тегов для гибкой категоризации задач.
- **Дедлайны и сроки:** Указание даты выполнения, визуальное выделение просроченных задач.
- **Поиск и фильтрация:** Быстрый поиск задач по ключевым словам и фильтрация по тегам/статусам.
- **Персистентность:** Автоматическое сохранение и загрузка задач в локальный файл `tasks.json`.
- **Логирование и безопасность:** Ведение подробных логов в папке `logs/` и защита от запуска нескольких экземпляров приложения (PID-контроль).
- **Горячие клавиши:** Удобная навигация и управление с клавиатуры.

---

## 🛠 Требования

- **Python** версии **3.8** или выше.
- Дополнительные библиотеки устанавливать **не нужно** — проект использует исключительно стандартную библиотеку Python (включая встроенный модуль `tkinter`).

---

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/task-manager.git
   cd task-manager
   ```

2. **Запустите приложение:**
   - **В Windows:** Дважды кликните по файлу `start.bat` или выполните в терминале:
     ```bash
     python task_manager.py
     ```
   - **В Linux / macOS:**
     ```bash
     python3 task_manager.py
     ```
