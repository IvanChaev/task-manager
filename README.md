# Task Manager 📋

Лёгкий, современный десктопный таск-менеджер с Kanban-доской, тегами, приоритетами, дедлайнами и удобным графическим интерфейсом. Написан на чистом Python с использованием `tkinter` — без сторонних зависимостей.

«Программное обеспечение предоставляется "как есть" (AS IS), без каких-либо гарантий».

---

## ✨ Основные возможности

- **Kanban-доска:** 3 колонки статусов (*«К выполнению»*, *«В процессе»*, *«Готово»*).
- **Drag & drop:** перенос задач между колонками перетаскиванием левой кнопкой мыши, удаление — перетаскиванием в корзину 🗑.
- **Сортировка внутри колонки:** кнопки ▲/▼ на каждой карточке; порядок сохраняется в файл данных.
- **Контекстное меню:** правый клик по задаче — «Редактировать», «Переместить в», «Удалить»; правый клик по пустому месту колонки — «Новая задача».
- **Приоритеты:** цветовая индикация (*Высокий*, *Средний*, *Низкий*) и фильтр по приоритету.
- **Система тегов:** создание, переименование, удаление и назначение цветных тегов; фильтрация по тегам одним кликом.
- **Дедлайны и сроки:** указание даты выполнения, визуальное выделение просроченных задач.
- **Поиск:** мгновенная фильтрация по ключевым словам в названии и описании (Ctrl+F).
- **Горячие клавиши:** Ctrl+N — новая задача, Ctrl+F — поиск, Ctrl+S — сохранить диалог, Esc — закрыть окно.
- **Синхронная прокрутка колонок:** колёсико листает все колонки одновременно, каждая со своей скоростью — все упираются в конец одновременно.
- **Персистентность:** автоматическое сохранение в `tasks.json`, порядок карточек сохраняется.
- **Логирование и безопасность:** логи в папке `logs/`, защита от запуска нескольких экземпляров (PID-контроль).

## 🆚 Преимущества перед Notion и Anytype

**Task Manager** — это осознанно минималистичный инструмент для личных задач. Он не претендует на роль замены полноценного комбайна, но в своей нише «быстрый личный таск-менеджер» выигрывает по ряду ключевых параметров:

| Критерий | Task Manager | Notion | Anytype |
|---|---|---|---|
| **Данные** | Один локальный файл `tasks.json` — всегда у тебя, в открытом JSON-формате | Облако Notion (доступ без интернета — только через кэш/плагины) | Локально, но с синхронизацией и шифрованием |
| **Аккаунт** | Не нужен — запустил и работаешь | Обязателен, данные привязаны к аккаунту | Обязателен аккаунт для синхронизации |
| **Подписка** | Бесплатно навсегда, MIT-лицензия | Платные тарифы за расширенные возможности | Free-тариф ограничен, платные функции |
| **Запуск** | `python task_manager.py` — и готово | Тяжёлое веб-приложение (браузер/Electron) | Отдельное приложение с установкой |
| **Ресурсы** | Потребляет килобайты RAM, открывается мгновенно | Может «съедать» сотни МБ и грузиться секунды | Заметно тяжелее, чем обычный десктоп |
| **Приватность** | Данные физически не покидают твой компьютер | Анализ и хранение на серверах Notion | E2E-шифрование, но через инфраструктуру сервиса |
| **Сложность** | 3 колонки, теги, приоритеты, сроки — всё на виду | Бесконечная кастомизация, в которой легко утонуть | Многоуровневая структура с обучающей кривой |
| **Переносимость** | Скопировал `tasks.json` — перенёс все данные на любой ПК | Экспорт/импорт через отдельные форматы | Экспорт и миграция нетривиальны |

**Кому подойдёт Task Manager:**
- кому нужен мгновенный доступ к списку задач без ожидания загрузки;
- кто не хочет зависеть от аккаунтов, облаков и подписок;
- кому важна полная приватность и контроль над своими данными;
- кому хватает Kanban-доски, тегов и дедлайнов без сотен лишних настроек;
- разработчикам и энтузиастам, которые хотят открытый, читаемый и расширяемый код.

**Когда лучше выбрать Notion или Anytype:** если нужны командная работа, совместное редактирование, сложные базы данных, мобильные приложения и синхронизация между устройствами.

## 🛠 Требования

- **Python** версии **3.8** или выше.
- Дополнительные библиотеки устанавливать **не нужно** — используется исключительно стандартная библиотека (включая встроенный `tkinter`).
- Полноценная поддержка **Windows** (PID-контроль через `tasklist`/`taskkill`); на Linux/macOS приложение также работает, но без PID-проверки.

## 🚀 Установка и запуск

**Простая:**
1) Нажать [сюда](https://github.com/IvanChaev/task-manager/archive/refs/tags/v1.1.zip)
2) Распаковать архив в удобное место
3) Запустить start.bat

**Сложная:**
```bash
git clone https://github.com/IvanChaev/task-manager.git
cd task-manager
```

- **Windows:** дважды кликните по `start.bat` или выполните:
  ```bash
  python task_manager.py
  ```
- **Linux / macOS:**
  ```bash
  python3 task_manager.py
  ```

При первом запуске рядом со скриптом создаётся файл `tasks.json` — в нём хранятся все задачи. Можно указать свой файл данных:

```bash
python task_manager.py --data "C:\Мои\задачи.json"
```

## 🖱 Управление

| Действие | Как выполнить |
|---|---|
| Создать задачу | Кнопка «+ Новая задача», Ctrl+N или правый клик по пустому месту колонки |
| Сменить статус | Перетащить карточку в другую колонку или меню правой кнопки → «Переместить в» |
| Сортировать внутри колонки | Кнопки ▲ / ▼ на карточке |
| Удалить задачу | Перетащить на корзину 🗑 или меню правой кнопки → «Удалить» |
| Редактировать | Меню правой кнопки → «Редактировать» |
| Найти задачу | Строка поиска (Ctrl+F) |
| Фильтровать по тегам | Клик по тегу на верхней панели |
| Управлять тегами | Кнопка 🏷 на верхней панели |

## 📂 Структура проекта

```text
Task Manager/
├── tm/                     # Исходный код пакета
│   ├── __init__.py
│   ├── app.py              # Главное окно и логика TaskManager
│   ├── config.py           # Константы, палитра цветов и настройки
│   ├── dialog.py           # Диалоговые окна (задачи, теги)
│   ├── logger.py           # Настройка логирования
│   ├── store.py            # Управление хранилищем данных (TaskStore)
│   ├── utils.py            # Вспомогательные функции (даты, цвета тегов, хоткеи)
│   └── widgets.py          # Кастомные виджеты (карточки, колонки, корзина)
├── logs/                   # Логи работы приложения (создаётся при запуске)
├── task_manager.py         # Точка входа в приложение (с проверкой PID)
├── start.bat               # Скрипт быстрого запуска для Windows
├── requirements.txt        # Зависимости (стандартная библиотека, ничего не нужно)
├── LICENSE                 # Лицензия MIT
└── README.md               # Документация проекта
```

`tasks.json` не входит в репозиторий — он создаётся автоматически при первом запуске.
